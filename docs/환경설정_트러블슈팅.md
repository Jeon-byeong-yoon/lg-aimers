## 🔴 발생한 에러

```
ImportError:
A module that was compiled using NumPy 1.x cannot be run in
NumPy 2.2.6 as it may crash.

Traceback:
  script.py → joblib.load(MODEL_PATH)
  → sklearn → scipy → numpy.core.multiarray failed to import
```

---

## 🔍 원인 분석

| 항목 | 내용 |
|------|------|
| **현재 시스템 NumPy** | `2.2.6` (Anaconda 기본 환경) |
| **필요 NumPy** | `<2.0` (scikit-learn 1.8.0 / scipy가 NumPy 1.x 기준으로 컴파일됨) |
| **문제 패키지** | `bottleneck`, `scipy.sparse`, `sklearn` 모두 NumPy 1.x 빌드 |
| **핵심 원인** | Anaconda base 환경의 NumPy 버전이 너무 높아서 충돌 발생 |

## ✅ 해결 방법 (권장: 방법 1)

### 방법 1 — conda 가상환경 새로 생성 ⭐ 권장

베이스 환경을 건드리지 않아 가장 안전합니다.

```bash
# 1. Python 3.11 기반 새 환경 생성
conda create -n lgaimers python=3.11 -y

# 2. 환경 활성화
conda activate lgaimers

# 3. requirements.txt 기반 설치
pip install scikit-learn==1.8.0 joblib==1.5.3 pandas==2.3.3

# 4. numpy 버전 다운그레이드 (중요!)
pip install "numpy<2"

# 5. script.py 실행
cd "/Users/jeonbyeong-yoon/Desktop/.무제 폴더/lg aimers 관련/공모전 dataset/open/baseline_submit"
python script.py
```
