# 성능 제출 계획

> 실제 제출 작업 위치: `submissions/by_submitter/`
>
> 새 제출본을 만들 때는 담당자 폴더의 `submit.zip`, `설명.md`, 상위
> `README.md` 기록을 한 단위로 갱신합니다.

## 검증 원칙

- 학습: 2019~2023 시즌, 검증: 2024 시즌
- 평가: Brier Score와 대회 Brier Skill Score(BSS)를 함께 기록
- 평가 데이터 행 간 통계나 후처리를 사용하지 않음
- 최종 모델은 모델 선택이 끝난 뒤 2019~2024 전체 데이터로 재학습

## 제출 순서

1. 공식 RandomForest 베이스라인: 서버 실행 및 파이프라인 기준점 확인
2. 안정형 앙상블: ExtraTrees 70% + HistGradientBoosting 30%
3. 보정형 앙상블: 2024 홀드아웃에서 학습한 affine 확률 보정

안정형을 우선 제출한다. 보정형은 홀드아웃 BSS가 더 높지만 2024의 확률 평균
이동이 2025에도 이어진다는 추가 가정이 있으므로 별도 리더보드 실험으로 취급한다.

## 담당자별 제출

| 담당자 | 제출 파일 | 역할 |
| --- | --- | --- |
| 전병윤 | `submissions/by_submitter/전병윤_RF_기준선/submit.zip` | 기준 점수 및 서버 확인 |
| 이준형 | `submissions/by_submitter/이준형_안정형/submit.zip` | 1순위 안정형 성능 확인 |
| 오현기 | `submissions/by_submitter/오현기_보정형/submit.zip` | 확률 보정 효과 확인 |

제출자는 자신의 경로에 있는 `submit.zip`만 그대로 업로드하고, 완료 후
`submissions/by_submitter/README.md`의 결과 표를 즉시 갱신합니다.

## 재현 명령

```bash
/opt/anaconda3/envs/lgaimers/bin/python scripts/train_models.py
/opt/anaconda3/envs/lgaimers/bin/python scripts/package_submission.py
/opt/anaconda3/envs/lgaimers/bin/python scripts/package_submission.py \
  --variant affine --output submissions/ensemble_affine.zip
```

ZIP에는 `script.py`, `requirements.txt`, `model/ensemble.joblib`만 포함한다.
패키징 결과를 바로 제출하지 않고 담당자 폴더로 배치한 뒤 그 복사본을 최종 제출본으로
간주합니다. 배치 후에도 ZIP 무결성과 내부 파일 목록을 다시 확인합니다.
