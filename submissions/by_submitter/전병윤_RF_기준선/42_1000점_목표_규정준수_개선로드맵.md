# 1000점 목표 규정 준수 개선 로드맵

## 1. 목표와 기준선

- 현재 최고 기준선: V41, Public `900.7385360187`
- 목표: Public/Private `1000+`
- 학습 데이터 타겟 평균을 기준으로 한 근사 필요 Brier 개선폭: 약 `2.48e-4`
- V41 이후의 가중치·하이퍼파라미터 미세 조정만으로는 목표 개선폭을 만들기 어려우므로, 검증 구조와 신규 안정 신호 발굴에 집중한다.

## 2. 공통 규정 준수 원칙

모든 실험·학습·추론에 다음을 강제한다.

1. 주최 측이 제공한 `train.csv`, `test.csv`, `trackman_history.csv`만 사용한다.
2. 외부 데이터와 외부 API를 사용하지 않는다.
3. 학습 행은 해당 투구 직전까지 확인 가능한 정보만 사용한다.
4. 현재 투구의 실제 위치·코스·판정·결과·제구 성공 여부·실제 구종·Trackman 측정값을 피처로 사용하지 않는다.
5. 2025 Trackman 데이터를 사용하지 않는다.
6. `test.csv`의 다른 행을 이용한 누적·rolling·빈도·순위·분포·Target Encoding·사후 보정을 금지한다.
7. 테스트 피처는 해당 행 입력과 학습 시 고정한 lookup/모델로만 계산한다.
8. 검증 피처의 통계·보정·가중치는 해당 검증 구간의 이전 데이터로만 학습한다.
9. 고정 시드, Python/패키지 버전, 학습 및 추론 절차를 기록한다.

## 4. 구현 로드맵

### V77 — V41 시간 블록·세그먼트 오류 진단

- 시즌·월 블록별 Brier loss 계산
- 투수 이력 표본 수, Trackman 이력, 카운트, 주자, 손잡이 조합별 손실 기여도 계산
- V17/Form/Context 간 예측 불일치와 오차의 관계 분석
- 산출물: 다음 실험의 최우선 세그먼트 1개 선정

### V78 — 베이지안 축소 Form Delta

- `prev1/3/5 - long_term` 변화량과 최근 기울기 생성
- `asof_pitcher_n`에 따른 신뢰도 축소
- V77에서 실제 손실이 큰 표본 수 구간에서 우선 평가

### V79 — 통합 As-of 피처 엔진

- 학습 행은 `shift(1)` 및 과거 시점 정보로만 누적통계 생성
- 테스트는 학습 전체에서 고정한 lookup으로 각 행을 독립 변환
- 투수·카운트·손잡이·구종군·휴식/역할 대체 신호의 계층 prior 검증

### V80 — 제구 실패 유형 경향 전문 모델

- 공식 as-of 가운데/`middle`, 반대 방향/`reverse`, 볼 경향을 분리 신호로 사용
- 현재 투구 사후 정보는 사용하지 않음
- 단일 복잡 모델보다 규제된 전문 모델의 소량 앙상블로 검증

### V81 — 표본 수 기반 동적 전문가 가중치

- `asof_pitcher_n`, `asof_batter_n`, `asof_pitcher_pitchmix_n`의 신뢰도로 Form/Context/Base 가중치를 완만하게 조정
- 투수 ID를 직접 외우는 게이트는 사용하지 않음

### V82 — 모델 불일치 기반 국소 확률 수축

- 행별 V17/Form/Context 예측 표준편차와 범위 계산
- 불일치가 큰 행에만 학습 OOF에서 고정한 약한 수축 적용
- 테스트 분포를 보고 임계값을 바꾸지 않음

### V83 — 시즌 안정성 피처 선택과 최종 앙상블

- 시즌/시간 블록별 신호 방향이 안정적인 피처만 유지
- V78–V82 중 독립적인 이득이 확인된 구성만 제한적으로 결합

## 5. 공통 채택 기준

실험 후보는 아래를 모두 확인한다.

1. 2022·2023·2024 시즌 수준에서 V41 대비 하락 없음
2. 시간 블록 개선 승률 최소 70%
3. 평균과 중앙값 Brier gain 모두 양수
4. 최악 블록의 하락이 사전 설정한 한계 이내
5. 다중 시드에서 개선 방향 유지
6. 최종 격리 holdout을 후보 선정 전에 조정에 사용하지 않음
7. 1000점 목표 주요 제출 후보는 V41 대비 Brier gain `5e-5` 이상을 원칙으로 함

## 6. 제출 관리

- 각 단계는 진단 → 단일 가설 구현 → 시간 블록 검증 → 규정 감사 순으로 진행한다.
- 통과하지 못한 단계는 ZIP을 생성하지 않는다.
- 통과 후보도 V41 구조로 패키징하고 서버 방식 격리 추론을 통과한 후에만 제출 후보로 올린다.
- 기준선 `submit_v41.zip`과 실제 업로드용 `submit.zip`은 사전 검증 전에 덮어쓰지 않는다.

## 9. V78 Bayesian 축소 Form Delta 결과

- 실행 코드: `scripts/evaluate_v78_bayesian_form_delta.py`
- 상세 지표: `artifacts/v78_bayesian_form_delta_metrics.json`
- 공식 `asof_*` 피처만으로 최근 1·3·5경기 성공/가운데 비율의 장기 기준선 대비 차이와 1→5경기 추세를 생성했다.
- `asof_pitcher_n / (asof_pitcher_n + k)`로 변화량을 축소했다.
- 실험 강도: `k=50`, `200`, `500`, `1000`
- 평가: 3개 시즌 Brier + 12개 시즌×월 블록

최고 2024 gain 후보인 `k=500` 결과:

| 항목 | 결과 |
|---|---:|
| 2022 gain | `-2.8849e-6` |
| 2023 gain | `+1.1264e-6` |
| 2024 gain | `+1.3463e-6` |
| 블록 개선 | `7 / 12` |
| 블록 승률 | `58.3%` |

- 2024는 소폭 개선했지만 목표 기준 `5e-5`에 크게 미달했다.
- 2022 전체와 2022년 3–5월 블록(`-3.8721e-5`)이 하락했다.
- 모든 축소 강도의 블록 승률이 `58.3%`로 동일해 안정적 개선으로 보기 어렵다.

### 최종 판정

- **기각**: `submit_ready=false`
- 제출 ZIP 생성 안 함
- V41 기준선 유지
- V79에서는 단순 최근 폼 확장이 아니라, 학습·검증·추론이 같은 코드를 사용하는 통합 As-of lookup과 표본 수 피처 정합성을 우선 검증한다.

- 공통 변환기: `scripts/asof_features_v79.py`

  - `hierarchy`: rates + 투수/타자 신뢰도·합의·차이
  - `pitchmix`: hierarchy + 구종군 entropy·최대 비중·표본 신뢰도
- 모든 prior는 검증 연도보다 이전인 학습 시즌에서만 고정했다.

| 후보 | 2022 gain | 2023 gain | 2024 gain | 블록 승률 | 판정 |
|---|---:|---:|---:|---:|---|

| hierarchy | `+2.0234e-5` | `-7.7260e-6` | `-2.6608e-6` | `58.3%` | 기각 |

### 해석과 판정

- `rates`는 2024에서 V41 이후 후보 중 의미 있는 `+6.29e-6`을 냈지만 2022·2023을 동시에 손상했다.
- 계층 합의 피처는 2022를 크게 개선했으나 2023·2024에 전이되지 않았다.
- 구종 혼합 신뢰도는 독립적인 개선 신호를 만들지 못했다.
- 모든 후보가 세 시즌 동시 개선과 블록 승률 70% 기준을 통과하지 못했다.
- **최종 기각**, 제출 ZIP은 생성하지 않고 V41을 유지한다.

## 12. V81 표본 수 기반 동적 전문가 가중치 결과

- 실행 코드: `scripts/evaluate_v81_dynamic_expert_weights.py`

- 공식 `asof_pitcher_n`, `asof_batter_n`만으로 행별 신뢰도를 계산했다.
- 신뢰도 기준점은 각 검증 연도의 이전 시즌에서만 고정했다.
- `form_only`: 투수 표본 수에 따라 Form↔V17 가중치 이동
- `dual`: 투수 표본은 Form, 타자 표본은 Context 가중치에 반영
- smoothing 강도 `200/500/1000`, 가중치 진폭 `0.02/0.05/0.08`, 총 18개 후보를 검증했다.
- 모든 행에서 V17+Form+Context 가중치 합은 1을 유지했다.

최고 후보는 `form_only`, smoothing `200`, 진폭 `0.02`였다.

| 항목 | 결과 |
|---|---:|
| 2022 gain | `-3.1584e-7` |
| 2023 gain | `-3.3163e-7` |
| 2024 gain | `-2.3996e-7` |
| 블록 승리 | `3/12` |
| 블록 승률 | `25.0%` |

- 18개 후보 전부 2024 gain이 음수였다.
- 세 시즌 동시 개선 후보도 0개였다.
- 투수/타자 이력 표본 수는 개별 모델의 상대적 신뢰도를 안정적으로 구분하지 못했다.
- **최종 기각**, V41의 고정 `0.55/0.32/0.13` 가중치를 유지한다.
