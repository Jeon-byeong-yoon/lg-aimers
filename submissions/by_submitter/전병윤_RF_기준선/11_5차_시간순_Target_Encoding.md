# 5차 시간순 선수 Target Encoding

> 담당: 전병윤

## 목적

숫자 크기에 의미가 없는 `pitcher_id`, `batter_id`를 선수별 과거 제구 성향으로
표현합니다. 현재 행 또는 같은·미래 시즌의 정답은 사용하지 않습니다.

## 누수 방지

- 각 학습·검증 행은 해당 시즌보다 이전 시즌의 정답만 사용
- 2022 행: 2019~2021로 인코딩
- 2023 행: 2019~2022로 인코딩
- 2024 행: 2019~2023으로 인코딩
- 실제 2025 행: 공식 학습 데이터 2019~2024로 만든 고정 매핑 사용
- 테스트 데이터 내부 빈도, 평균, target encoding은 사용하지 않음

## 피처

- 투수 성공률: smoothing strength 50, 200
- 타자 상대 투구 성공률: smoothing strength 50, 200
- 투수·타자 과거 표본 수의 `log1p`
- 과거가 없는 선수는 모델의 결측 처리로 fallback

V4 Trackman HGB 위에 추가해 2022·2023·2024 모든 시즌에서 개선되는 경우에만
ExtraTrees 블렌드와 최종 V5 후보로 확장합니다.

## 로컬 제출 후보

- 파일: `submit_v5.zip`
- 공식 2019~2024 학습 데이터 전체로 최종 재학습
- 테스트에는 학습 데이터로 만든 고정 선수 매핑과 고정 Trackman 집계표만 적용
- 테스트 데이터 내부 빈도·통계·target encoding 미사용
- ZIP 무결성 검사 및 평가 서버 방식 5행 모의 추론 통과
- 로컬 검증 완료 후 리더보드에 제출하여 실제 평가 효과 확인
