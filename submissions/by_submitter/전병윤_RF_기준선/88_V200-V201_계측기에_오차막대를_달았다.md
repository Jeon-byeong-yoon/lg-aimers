것이었나.** 이 프로젝트에서 "닫혔다"는 선언이 세 번 틀렸고 세 번 다 계측기 결함이었다.

## 1. 판독을 믿을 수 있는 조건이 정확히 나뉜다

V162의 표가 그 경계를 그대로 보여준다.

```
feature_225   2024  +0.07      ← 신경망 재학습 → 후보와 기준선의 뽑기가 다름
feature_400   2024  -1.10
feature_500   2024  -1.05

drift_r75_w0.12   2023 +30.66  ← 재구성에서 계산 → 같은 뽑기가 양쪽에
drift_r400_w0.08  2023 -32.02
```

> **후보와 기준선이 같은 뽑기를 공유하면 판독을 믿을 수 있고, 아니면 잡음이다.**

이 기준으로 과거 실험이 둘로 갈린다.

| 신뢰 가능 (캐시된 예측, 같은 뽑기) | 의심 (확률적 성분 재학습) |
|---|---|
| 보정층 전부 (V168, V172–V184) | **V160·V162 reliability scale** |
| 가중치 탐색 (V159, V163, V198) | V157 Context 하이퍼파라미터 |
| V162의 드리프트 절반 | V158 인코딩 strength |
| | V97·V107 Form, V115·V129 신경망, V130·V140 FM |
| | V123·V124 CatBoost capacity |

## 2. V200 — 측정된 귀무값: 과거 판독은 0.13 표준편차였다

캐시된 scale-300 뽑기 9개로 **짝짓지 않은 잡음을 직접** 계산했다(36쌍). 가정이 아니다.

| | 2022 | 2023 | 2024 |
|---|---|---|---|
| **sd** | 9.73 | 22.53 | **8.67** |
| 범위 | 37.07 | 94.55 | 29.87 |

**V160과 V162의 모든 배율 판독이 이 잡음 위에서 이뤄졌다.** 그 값들이 ±1.1이었으니

    V160   75 → -0.72     300 → +0.77     600 → -0.25
    V162  225 → +0.07     400 → -1.10     500 → -1.05

**전부 0.13 표준편차 안이다. 배율 결정 전체가 잡음이었다.**

### 짝짓기가 8.1배 줄였다

`sd 8.67 → 1.07`. reliability 배율은 105열 중 `ins_pitcher_reliability` 하나만 바꾸고
(V160이 Form은 배율에 **비트 단위로 무관**함을 보였다 — HGB가 그 열로 분할하지 않는다),
같은 시드면 두 신경망이 동일한 초기 가중치에서 출발하므로 두 적합이 거의 붙는다.

**Form을 재학습하지 않아도 되는 것이 이 실험을 싸게 만든 이유이기도 하다.**

## 3. 깨끗한 계측기의 첫 판독 — 그리고 고원 검사

| 배율 | 2022 | 2023 | **2024** |
|---|---|---|---|
| 150 | −0.99 ± 0.13 | −0.15 ± 2.33 | −0.16 ± 0.23 |
| 190 | −1.06 ± 0.76 | +0.65 ± 2.18 | +0.06 ± 0.64 |
| **225** | −0.10 ± 0.42 | +0.92 ± 0.76 | **+1.43 ± 0.55** |
| 260 | −0.82 ± 0.22 | +2.41 ± 2.21 | +0.15 ± 0.44 |
| **300 (현행)** | 0 | 0 | 0 |
| 450 | −0.38 ± 0.46 | +0.10 ± 1.48 | +0.07 ± 0.58 |
| 600 | +0.23 ± 0.61 | +0.13 ± 2.15 | −0.29 ± 0.55 |

**배율 225가 2024에서 `+1.43 ± 0.55` (2.6 SE)** — 이 프로젝트가 측정한 **첫 유의한 성분
수준 효과**였다. 2022는 `−0.10 ± 0.42`로 0과 구별되지 않아, 엄격한 게이트로는 기각이지만
V144의 −1.86이나 V151의 −32.36과 달리 "손실"이 아니라 "알 수 없음"이었다.

**그래서 제출 전에 고원인지 확인했다.** 2024 열이 `−0.16 / +1.43 / 0 / +0.07 / −0.29`로
단조롭지 않고 225만 튀어나왔고, 배율 4개 × 시즌 3개 = 12개 판독 중 2.6 SE 하나는 우연으로도
약 11% 확률이다.

### V201 — 양쪽 이웃이 둘 다 0이다

`190 → +0.06 ± 0.64`, `260 → +0.15 ± 0.44`. **능선이 아니라 고립된 봉우리다. 그 11%였다.**

그리고 부수 관찰: **2022는 300 미만 모든 배율에서 음수**(−0.99 / −1.06 / −0.10 / −0.82)이고
300 이상에서 0 근처다. 2024는 225를 빼면 어디서나 ±0.3 안이다.

> **reliability scale은 150–600 구간에서 실제로 평평하고 300이 무엇보다도 나쁘지 않다.**
> 이 상수는 이제 **제대로 된 계측기로** 닫혔다 — 잡음으로 닫은 것이 아니다.

## 4. 이 라운드가 남긴 것 — 오차막대

점수는 그대로지만 **처음으로 효과의 유의성을 말할 수 있는 계측기가 생겼다.**

| | 이전 (단일 뽑기) | V200 (짝지은 5시드) |
|---|---|---|
| 2024 판독 잡음 sd | **8.67** | **1.07** |
| ±1점 효과 | 0.12 SE — 검출 불가 | 0.9 SE — 검출 가능 |
| 판정 근거 | "부호가 양수인가" | "몇 SE인가" |

이전까지 폴드 판독에는 오차막대가 없었다. 최소 시즌 규칙이 14/15로 잘 작동한 것은
**부호만 읽었기 때문**이고, 크기의 비율이 `0.13`~`3.40`으로 흩어진 것도 이 잡음으로
설명된다.
