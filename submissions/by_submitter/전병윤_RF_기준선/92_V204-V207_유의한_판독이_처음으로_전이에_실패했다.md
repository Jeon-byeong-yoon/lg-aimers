# V204–V205 — 1000트리 판독은 유의했지만 전이되지 않았다

기준선: **V199, Public 1083.2461959655 (유지)**. V207 (트리 1200 → 1000) **기각, −0.7400**.

⑤("CatBoost capacity + 자체 reliability, 4시간+")를 그대로 돌리지 않았다. V202·V203의
규칙과 코드 정독이 ⑤를 두 개의 다른 물건으로 쪼갰고, 둘 다 원래 계획보다 싸게 닫혔다.

---

## 1. 설계를 바꾼 두 관찰

**reliability 절반은 트리 모델에서 원리적으로 죽어 있다.** `ins_pitcher_reliability =
inside_n / (inside_n + scale)`은 scale이 무엇이든 `inside_n`의 순서를 보존하는 단조
변환이다. 트리의 분할은 순서에만 반응하므로 배율은 양자화 2차 효과로만 도달할 수 있다.
V160에서 Form(HGB)이 배율에 비트 단위로 무관했던 것과 같은 기제다. 참고로 CatBoost
블록의 배율은 300도 아닌 **모듈 기본값 150을 그냥 물려받고 있었다** — "미탐색"은
맞지만 탐색할 가치가 없는 상수였다.

**반복수에는 완벽한 계측기가 공짜로 존재한다.** learning rate가 고정(0.02)이므로 2400
iterations 모델의 앞 1200개 트리는 1200 모델과 **동일한 객체**다. `ntree_end`로 자르면
학습 12회로 곡선 9지점을 전부 읽고, 짝짓기는 HGB의 `iter_only_400`(SE 0.43)보다 좋다.
V123·V124가 1200을 고른 것은 짝짓지 않은 잡음 sd 8.67 위에서였다.

### 왜 과거에 안 보였나

옛 계측기의 잡음(sd 8.67)에서 ±1점 구조는 0.1 SE다. V123·V124의 1200 결정은 이 구조를
원리적으로 볼 수 없는 계측기 위에서 이뤄졌다.

## 3. V205 — reliability는 비트 단위로 무관 (예측 적중)

배율 150 → 600 (4배), 2024 폴드, 시드 42, 한 번의 학습:

- 열 검사: 스피어만 **정확히 1.0** (순서 보존), 값은 최대 0.33 이동
- **예측 차이: max `0.000e+00`, sd `0.000e+00` — 비트 단위 동일**
- 블렌드 판독: 세 시즌 전부 정확히 0

단조변환 논증이 근사가 아니라 **정확하게** 성립했다. CatBoost의 reliability 배율은
Form(HGB)과 마찬가지로 존재하지 않는 상수다. 축 폐쇄, 4시간짜리 스윕 회피.

### 무엇이 틀렸나

계측기 자체가 틀린 것은 아니다 — 짝지은 판독은 "검증 시즌들에서 1000이 1200보다
낫다"를 측정했고 그 측정은 통제까지 완벽했다. 틀린 것은 **폴드 → 테스트 전이 가정**이다.

1. **효과 크기가 전이 잡음에 잠긴다.** 이 축의 실측/기대 비율은 역사적으로 0.13~3.40으로
   흩어졌다. 기대 +0.5짜리 후보는 전이 오차(±1 남짓)가 부호를 뒤집을 수 있고, 실제로
   뒤집혔다. V189~V199의 성공은 전부 기대값이 더 크거나(+3.6~+10) 같은 기제의 반복이었다.
2. **반복수의 최적점은 학습 데이터 구성에 민감하다.** 단독 skill에서도 폴드마다 최적점이
   달랐다(2023은 1200, 2024는 400 쪽). 배포 모델은 2019–2024 전체로 학습해 2025를
   예측하는 물건이라, 검증 폴드들이 합의해도 그 합의가 테스트 구성으로 이어진다는 보장이
   없다. 상수 재검토(V200~V203)가 전부 "현행 유지"로 끝난 것과 합치면, **훈련된 상수를
   검증 폴드 판독으로 미세 조정하는 일 자체의 기대값이 음수**라는 것이 이 라운드의 결론이다.

### 교훈

> 성분 수준 2.7 SE는 "검증 시즌에서 실재하는 효과"를 보장할 뿐, 폴드 → 테스트 전이를
> 보장하지 않는다. 기대값 +0.5 규모의 상수 미세 조정은 제출 가치가 없다 — 전이 잡음이
> 그보다 크다.

reliability 축 폐쇄(§3)는 이 결과와 무관하게 유효하다 — 그쪽은 비트 단위 동일이라
전이할 것 자체가 없다.
