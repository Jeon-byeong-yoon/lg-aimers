# 4차 Trackman 과거 로그 피처 실험

> 담당: 전병윤

## 연결 감사

- 메인 `pitcher_id`와 `pitcher_trackman_id` 교집합: 0
- 메인 `batter_id`와 `batter_trackman_id` 교집합: 0
- 팀 코드 체계도 서로 달라 추정 매핑을 사용하지 않음

선수나 팀을 억지로 연결하지 않고, 공통으로 명확하게 대응되는 투수손·타자손·월·
볼카운트·스트라이크카운트만 집계 키로 사용합니다.

## 누수 방지

- 검증 시즌보다 엄격히 이전 시즌의 Trackman 로그만 집계
- 2022 검증: 2019~2021 로그
- 2023 검증: 2019~2022 로그
- 2024 검증: 2019~2023 로그
- 실제 2025 추론: 2019~2024 로그
- 평가 데이터 행 간 통계는 사용하지 않음

## 집계 피처

- 구속, 회전수, 수직·수평 무브먼트, 익스텐션, 릴리스 위치, 존 통과 속도의 평균·표준편차
- fastball·breaking·offspeed·other 구종군 비율
- 집계 표본 수

먼저 HGB 단일 모델로 세 시즌을 검증하며 모든 시즌에서 V2 HGB보다 개선된 경우에만
앙상블 및 최종 제출 후보로 확장합니다.

## 로컬 제출 후보

- 파일: `submit_v4.zip`
- 원본 Trackman CSV는 ZIP에 포함하지 않음
- 공식 2019~2024 로그에서 만든 2025용 고정 집계표만 모델 번들에 포함
- ZIP 무결성 검사 및 평가 서버 방식 5행 모의 추론 통과
- 로컬 검증 완료 후 리더보드에 제출하여 실제 평가 효과 확인

## 실제 리더보드 결과

| 제출 | Public Score | 변화 |
| --- | ---: | ---: |
| V2 기준선 | 773.5628224525 | 기준 |
| V4 Trackman | 773.5857844860 | +0.0229620335 |

V4는 실제 평가에서도 상승했지만 개선 폭은 약 0.023점으로 매우 작습니다. 따라서
Trackman 과거 집계 방향은 유효하나 현재의 손·월·카운트 단위 전역 집계만으로는 추가
정보량이 제한적이라고 판단합니다. 이후 실험의 기준선은 V4로 갱신하되 단순 모델
튜닝보다 더 세밀하면서도 명확히 대응 가능한 과거 집계 키와 안정적인 확률 보정을
우선 검토합니다.
