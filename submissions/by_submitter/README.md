# 3인 제출 배정표

이 디렉토리가 팀의 **유일한 실제 제출 작업 위치**입니다. 새 모델 제출을 준비할 때는
담당자 폴더의 `submit.zip`과 `설명.md`를 갱신하고, 제출 결과는 이 문서에 기록합니다.
다른 위치의 ZIP은 과거 보관본 또는 빌드 중간 산출물이며 업로드하지 않습니다.

## 개인 작업 문서 위치

- 전병윤이 수행한 모델링·전처리·실험 관련 Markdown 문서는
  `전병윤_RF_기준선/`에 저장합니다.
- 새 문서는 작업 내용이 드러나는 이름으로 만들고, 해당 폴더의 `설명.md`에서
  주요 결과를 연결하거나 요약합니다.
- 공통 대회 규칙과 전체 프로젝트 안내만 기존 `docs/`에 유지합니다.

## 주의

- 세 파일을 한 계정에서 모두 제출하지 않고 배정된 참가자가 하나씩 제출한다.
- 팀 병합 전 개인 제출 의무 및 계정 중복 참가 규칙은 대회 페이지의 최신 공지를 따른다.
- ZIP의 압축을 풀어 내부 파일을 다시 압축하지 않는다. 준비된 `submit.zip`을 그대로 올린다.
- 새 모델은 학습·시간순 검증·서버 모의 추론·압축 무결성 검사를 모두 통과한 뒤에만 담당 폴더에 배치한다.
- 모델을 교체하면 `설명.md`의 모델명, 검증 점수, 목적도 같은 시점에 수정한다.
- 제출 직후 Public Score, 제출 시각, 정상 실행 여부를 위 표에 기록한다.
